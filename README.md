# Нохчийн мотт: первый урок

Это первый статический прототип для Firebase Hosting. Он учит базовым фразам с русского на чеченский:

- дополнительные чеченские буквы и сочетания для правильного произношения;
- приветствия;
- вежливые слова;
- короткие ответы;
- знакомство;
- фразы для понимания собеседника.

## Правило обучения

- Главный экран показывает полноценный календарь месяца: название месяца, дни недели, даты и номер недели.
- Блок с буквами и звуками находится в кнопке `Правила` на главном экране.
- Материал дня открывается после нажатия на доступный день в календаре.
- Понедельник-пятница: каждый день открывается 5 новых слов или фраз.
- Будущие дни в календаре видны, но закрыты до наступления своего дня.
- Уже открытые дни можно открыть снова и повторять отдельно.
- Суббота-воскресенье: новых слов нет, приложение показывает все 25 слов недели для повторения.
- Тренировка берет вопросы только из уже доступных слов: сегодняшние слова, открытая часть недели или выбранный открытый день.
- Прогресс сохраняется в браузере на этом устройстве.

Перед словами ученик видит отдельный блок произношения: `хь`, `аь`, `оь`, `уь`, `кх`, `гI`, `хI`, `кI`. Например, `х + ь = хь`, и это не обычная русская `х`.

## Админ-панель

Клиентская часть: `public/index.html`.

Админская часть: `public/admin.html`.

В админке можно редактировать слова, правила произношения и вставлять ссылки на аудиофайлы из GitHub. Сейчас сохранение идет в браузерное хранилище на этом устройстве. Перед публичным запуском админку нужно защитить входом и перенести материалы в Firestore или отдельный JSON-файл из репозитория.

Кнопка озвучки в клиентском приложении появляется только у тех слов и правил, где в админке заполнена ссылка на аудиофайл. Если аудиоссылки нет, динамик скрыт.

## PWA для смартфонов

Приложение подготовлено как PWA: добавлены `manifest.webmanifest`, иконка и `sw.js`. После публикации на HTTPS-домене его можно будет установить на смартфон:

- iPhone: открыть сайт в Safari, нажать `Поделиться`, затем `На экран Домой`.
- Samsung/Android: открыть сайт в Chrome, нажать `Установить` или `Добавить на главный экран`.

При открытии как локальный `file://` PWA-установка не включается; она заработает после публикации на GitHub Pages или Firebase Hosting.

## GitHub Pages

Репозиторий приложения: `Unnamed00000/tihaya-gavan`.

Публичная ссылка: `https://unnamed00000.github.io/tihaya-gavan/`.

Для GitHub Pages файлы из папки `public/` нужно положить в корень репозитория или в выбранную Pages-папку. Аудио удобно хранить в папке `audio/`, а в админке вставлять Raw-ссылку такого вида:

```text
https://raw.githubusercontent.com/Unnamed00000/tihaya-gavan/main/audio/salam.mp3
```

## Как запустить локально

Откройте `public/index.html` в браузере.

Firebase уже подключен через браузерный SDK в `public/firebase-init.js`. На локальном файле Analytics не запускается, а после публикации на Firebase Hosting начнет работать на настоящем домене.

## Как выложить на Firebase

В папке `chechen-learning-app` выполните:

```powershell
firebase use tihaya-gavan-f732b
firebase deploy --only hosting
```

`npm install firebase` пока не нужен, потому что этот прототип не использует сборщик. Он понадобится, когда приложение будет переведено на React/Vite или когда появятся Firestore, аккаунты, личный прогресс между устройствами и роли преподавателя.

Перед публичным запуском лучше попросить носителя чеченского проверить фразы и произношение. Первый набор собран по открытым разговорникам Omniglot, Wikibooks/Wikivoyage и русско-чеченским разговорникам.
