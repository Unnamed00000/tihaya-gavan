# Материал приложения

В этой папке лежит файл `content.json`.

Когда ты меняешь слова или правила в админке:

1. Нажми `Скачать content.json`.
2. Открой эту папку `data` на GitHub.
3. Замени файл `content.json` новым скачанным файлом.

После этого клиентская страница начнет брать новый материал отсюда.
